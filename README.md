An interactive coding mastery web platform designed to build rapid developer intuition through 10-second muscle memory drills, interactive memory visualization, and structured learning roadmaps.

## 🚀 Features

- **⚡ Synapse Blitz** — 10-second high-intensity code drills for muscle memory training across core programming languages.
- **🧠 Memory Vision** — Visual interactive engine illustrating heap vs. stack allocations, pointer references, and memory layouts in real time.
- **🗺️ Interactive Roadmaps** — Step-by-step career tracks from syntax fundamentals to advanced system design.
- **🔊 Dynamic Sound Engine** — Immersive audio cues and keyboard feedback for flow-state learning sessions.
- **Zero Dependencies** — High-performance vanilla JavaScript, CSS, and semantic HTML that runs instantly in any browser.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure & Accessible UI)
- **CSS3** (Custom responsive design system, animations & dark mode)
- **Vanilla JavaScript (ES6+)** (Modular architecture: `blitz.js`, `drills.js`, `memory-vision.js`, `roadmap.js`, `audio.js`)

## 💻 Quick Start

Simply open `index.html` in any modern web browser or serve it with any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve .
```
